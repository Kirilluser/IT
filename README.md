## ✨ О проекте

> LocalSkills — это место, где знания двигаются по кругу.  
> Ты учишь кого-то — кто-то учит тебя.  
> Это честно, эффективно и по-человечески.

**Проект для тех, кто хочет:**

- 🎓 Учиться новому бесплатно  
- 👐 Делиться своим опытом  
- 🔍 Находить людей по интересам  
- 🌱 Развиваться в реальном сообществе  

---

## 🧩 Ключевые особенности

### 🎨 Многоуровневые визуальные темы
| Тема | Характер | Акцент |
|------|----------|--------|
| 🌸 Soft Minimal | спокойная, чистая | 🟦 бирюзовый |
| 🌈 Vibrant Friendly | яркая, дружелюбная | 🟧 коралловый |
| 💼 Calm Professional | уверенная, строгая | 🟦 синий |

> Все темы поддерживают **Light / Dark Mode** и строятся на CSS-переменных для полной кастомизации.

---

### 🔍 Интеллектуальный поиск
**Фильтры по навыкам и интересам:**

- Категория навыков  
- Уровень (Beginner → Expert)  
- Формат встреч (онлайн / офлайн)  
- Город  
- Теги  

💨 Мгновенный поиск без лишних кликов.

---

### 👤 Расширенные профили пользователей
Каждый профиль содержит:

- 📸 Фото  
- 💡 Навыки для обучения  
- 📚 Навыки для изучения  
- ⭐ Уровень  
- 🖥️ Формат встреч  
- 🏷️ Теги и интересы  
- 📝 Мини-портфолио  

> Все это помогает быстро находить нужных людей и строить реальные обмены знаниями.

---

### ⚡ Современный интерфейс
Используется:

- Shadcn/ui + Radix UI  
- Tailwind CSS v4  
- Кастомные CSS-переменные  
- Анимации, модалки, адаптивные ховеры  

💎 Быстро, плавно, красиво.
